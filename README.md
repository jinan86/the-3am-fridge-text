## The line

> 3am. Your water filter here: 400 litres cleaned, zero thank-yous. From now on the tap water tastes exactly like your manners.

The angle is the fridge's water filter — the part that works all night, purifies hundreds of litres, and never once gets thanked. Across 642 submissions when this was written, the water filter had zero mentions, while leftovers, pickles, cake, milk, ice and the door were everywhere.

## Run

```bash
python3 main.py
```

Writes the single line (125 characters, one line, no trailing newline) to `/output/entry.txt`. Fully deterministic: no randomness, no network, no clock — every run produces byte-identical output.
